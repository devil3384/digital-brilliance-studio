# Digital Brilliance Studio

Act as an expert web designer, senior full-stack developer, and UI/UX specialist.

Build a complete, modern, premium-looking and mobile-responsive business website for my business.

Design requirements:

Professional, clean and premium design

Modern typography, attractive colors, smooth animations and subtle hover effects

Beautiful hero section with a strong headline, description and clear call-to-action buttons

Responsive navigation menu for mobile and desktop

Professional services or products section with images

About Us, Why Choose Us, customer testimonials, FAQ and Contact sections

WhatsApp contact button, contact form, phone number and Google Maps location section

Footer with social media links

Fast loading, accessible design and basic SEO optimization

Functional requirements:

All buttons and navigation links must work

Add search, filtering or booking features if appropriate for the business

Store contact form submissions securely if a backend is configured

Use a database only when necessary

Never create fake customer reviews or invent business information

Use placeholders for business details that I have not provided

Do not expose API keys or sensitive credentials

Test the website and fix errors before considering it complete

Development workflow:

First create a beautiful homepage and consistent design system.

Build all required pages and responsive layouts.

Implement the necessary functionality.

Test navigation, forms and mobile responsiveness.

Explain how to preview and publish the website using free options.

Use modern, maintainable code and make the result look like a professional agency designed it. Prefer free resources and services wherever possible.

Before inventing any business-specific details, ask me for my business name, industry, services, contact information and preferred colors.
